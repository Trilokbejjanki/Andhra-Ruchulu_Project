# 🍽️ Andhra Ruchulu – Restaurant Website

Andhra Ruchulu is a responsive restaurant website developed to provide users with a simple and attractive way to explore food items, view the menu, add items to a shopping cart, and proceed to checkout.

## ✨ Features

* Responsive Restaurant Website
* Food Menu & Categories
* Food Gallery
* User Signup
* Add to Cart
* Update & Remove Cart Items
* Order & Checkout Interface
* Interactive Navigation
* Mobile-Friendly Design

## 🛠️ Technologies Used

* **HTML5** – Website structure
* **CSS3** – Styling and responsive design
* **JavaScript** – Interactive features and cart functionality

## 🔄 User Flow

**Home → Menu → Select Food → Add to Cart → View Cart → Checkout**

## 📌 Key Highlights

* Developed a responsive and user-friendly restaurant interface.
* Implemented interactive shopping cart functionality using JavaScript.
* Designed menu, food gallery, signup, cart, and checkout sections.

1. Clone the repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Explore the website and test the cart functionality.
